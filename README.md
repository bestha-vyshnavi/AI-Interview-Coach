# 🎯 InterviewIQ — AI Interview Coach

InterviewIQ is an interactive interview practice application designed
to help students and job seekers improve their interview answers.

## 🚀 Features

- Interview answer analysis
- Overall performance score
- Clarity score
- Confidence score
- Structure score
- Role relevance score
- Filler-word detection
- Role-specific keyword detection
- STAR-method guidance
- Practice history
- Progress tracking
- Downloadable interview report
- Interactive visualizations

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Regular Expressions
